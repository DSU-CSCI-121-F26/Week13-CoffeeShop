# Your coffee shop tests go here

At each step, drag that step's test from `check/coffeeshop/` into this folder, then run it.

| Step | Drag in |
|---|---|
| 1 | `MenuItemTest.java` |
| 2 | `DrinkTest.java` and `FoodTest.java` |
| 3 | `MenuTest.java` |
| 4 | `OrderTest.java` |
| 5 | `CoffeeShopTest.java` |
| 6 | `CoffeeShopAppTest.java` |

Drag a test in only **after** you start its step. A test that looks for a method you have not written yet
turns the whole test folder red, and then no test can run, not even the Challenges.
